# 艾艾精工形态相似选股器 (aiai-pattern-scanner)

> 以艾艾精工 (603580) 2026-07-02 启动为锚点，全市场量化扫描走势形态相似的票。

## 背景

艾艾精工在 2026-06 之前长期 21 元附近横盘，6 月底放量突破，7-8 月连续涨停，主升浪区间涨幅约 286%。本工具将该过程拆解为**双模板**，全 A 实时扫描，找出当前走势节奏相似的标的——包括"启动前蓄势"和"刚启动拉升初期"两类。

## 原理

**双模板提取**（自动检测启动日，规则：单日涨幅 > 8% 且 量 > 20日均量2倍 且 前30日累计涨幅 < 15%）

| 模板 | 区间 | 特征 | 用途 |
|------|------|------|------|
| 模板 A 蓄势段 | 启动前 60 个交易日 (2026-04-01 ~ 2026-07-01) | 缓步抬升蓄势，区间涨幅 41% | 找"启动前"的票 |
| 模板 B 拉升段 | 启动后 20 个交易日 (2026-07-02 ~ 2026-08-05) | 连续涨停，区间涨幅 105% | 找"刚启动"的票 |

**匹配算法**（对每只候选股同时与两个模板对齐）

1. **DTW 动态时间规整**——允许时间轴弹性伸缩，捕捉"节奏相似"
2. **形状相关系数**——去均值 Pearson 相关，衡量形态方向一致性
3. **量能形态**——前段缩量后段温和放量得高分
4. **涨幅接近度**——对数尺度距离

**综合分 = 形状(DTW+相关, 80%) + 量能(10%) + 涨幅(10%)**

**形状硬门槛**：`shape = dtw*0.5 + corr*0.5 ≥ 0.35`，防止"量能涨幅凑分"的假阳性。

**分类口径**

| 分类 | 条件 |
|------|------|
| 刚启动(拉升初期) | post_score ≥ 55 且 post_shape ≥ 0.35 且近 5 日回撤 ≤ 12% |
| 启动前(蓄势中) | pre_score ≥ 55 且 pre_shape ≥ 0.35 |
| 形态接近(观察) | max(pre, post) ≥ 48 |

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 全 A 扫描（默认流通市值 ≥ 10 亿，排除北交所，约 5-10 分钟）
python3 scanner.py

# 3. 快速演示（只用示例池的 7 只票跑一遍，几秒）
python3 scanner.py --pool csv --limit 7

# 4. 单票诊断（与艾艾精工模板逐项对比）
python3 main.py --code 600713

# 5. 生成可视化报告（叠加走势图）
python3 report.py examples/aiai_pattern_scan_20260823_1710.csv
```

## 完整参数

```bash
python3 scanner.py \
  --pool sina \            # 股票池来源：sina(全A在线) | csv(本地文件) | seed(内置种子)
  --limit 0 \              # 扫描数量上限，0 = 全部
  --workers 16 \           # 并发线程数（建议 8~24，过高触发限流）
  --min-mktcap 10 \        # 最小流通市值(亿)
  --max-mktcap 0 \         # 最大流通市值(亿)，0 = 不限
  --min-score 50 \         # 最低综合分门槛
  --top 30 \               # 输出 Top N
  --exclude-bj \           # 排除北交所（默认 true）
  --pre-days 60 \          # 蓄势模板长度
  --post-days 20 \         # 拉升模板长度
  --out outputs/scan.csv   # 输出文件路径
```

## 自定义股票池

`--pool csv` 模式下读 `stock_pool.csv`（无该文件回退到 seed）。CSV 至少含 `code` 列，可选 `name`、`province`、`industry`：

```csv
code,name,province,industry
600713,南京医药,江苏,医药商业
002415,海康威视,浙江,电子设备
...
```

## 输出说明

**CSV 文件**（aiai_pattern_scan_*.csv）

| 列 | 含义 |
|----|------|
| 代码 / 名称 / 现价 / 流通市值 | 基础信息 |
| 分类 | 启动前(蓄势中) / 刚启动(拉升初期) / 形态接近(观察) |
| 蓄势相似度 / 拉升相似度 | 与两个模板的综合分（0-100） |
| 蓄势段涨幅 / 拉升段涨幅 | 候选股对应窗口的实际涨幅 |
| 匹配段DTW / 匹配段相关 | 与分类对应段的形状指标 |
| 量能形态 | 0~1 分 |

形状相关 > 0.8 且 DTW < 2 → 高度相似

**HTML 报告**

含艾艾精工模板（红色粗线）与命中个股走势的归一化叠加图 + 明细表，开箱即可在浏览器打开。

## 数据源

- **新浪行情** `https://quotes.sina.cn/` —— 不复权，覆盖全 A，可能触发 456 限流
- **新浪行情中心** `https://vip.stock.finance.sina.com.cn/` —— 股票列表、流通市值
- **腾讯前复权** `https://web.ifzq.gtimg.cn/` —— 前复权数据，新浪失败时自动切换

`get_kline()` 已实现自动 failover：新浪返回非 JSON（限流 456）时无缝切换腾讯。

## 注意事项

- 工具为**形态量化筛选**，不构成投资建议
- 高分票建议人工复核 F10 基本面（除权、所属概念、近期公告等）
- "启动前(蓄势中)"分类样本数偏少是正常现象——长期横盘票本就稀缺
- `--workers` 过高可能被限流，建议先用 12 测试后逐步加
